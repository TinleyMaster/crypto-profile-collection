## 0. 诊断结论（TL;DR）

1. **板块拓扑落后于数据能力。** 早报 M0–M9 模块结构稳定（近期改动集中在 `build_daily_brief.py` 的 W-06~W-13：快照落库、T-1 变更日志、`opportunity_snapshot` 落表）。但项目近期一波大改——盘面异动扫描 v2（`00186e8`/`647b9cb`）、涨幅榜周期回测 + TRAIL 最优（`fe0455d`/`46f9113`）、爆仓极值回测 + 覆盖层（`4fbaee8`/`1f8a998`）、联动因子（稳定联动组 + issuer 维度 + 二阶受益，`9a4ac91`/`c155ac8`/`69c9fef`）、大户持仓趋势面板（`b5da424`）——这些能力都已写入 brief 的 M 字段，**却未沉淀为独立、清晰定位的早报板块**。
2. **同一结论多处重复。** 今日3句话 / 今日操作清单 / 交易方向 / 精选机会 / AI高亮 / 高危信号 围着同一批标的反复出现，依赖 `send_daily_brief.py:1018` 起一段脆弱的 `owners` 折叠去重逻辑。这是反模式 → 应"一份结论只在一处出现"。
3. **硬价格「交易方向」是 P0 责任雷区（已修，`855ce34`）。** 价格来自 `M0_ai_summary.trade_suggestions`（`send_daily_brief.py:1224`），曾与「大盘脉搏」不同源，正是 `早报可信度审计_2026-10-06.md` 的 P0 根因（BTC 写 115,000 / 实时 ≈86,000，偏离 +33.9%；ETH 写 4,200 / 实时 ≈2,714，偏离 +54.7%）。
   已修：`generate_morning_brief_ai_summary` 的 prompt **注入与大盘脉搏同源的 SSOT 实时价**（BTC/ETH 现价 + 24h 涨跌），并新增**后置门闸** `_filter_trade_ref_price`——命中标的参照价偏离实时价 >30% 整条作废，全废则 `no_trade_reason` 写「参照价与系统实时价严重偏离，已全部作废」。余下决策 = §5.#1「砍 vs 保留」（已由 P0 必改降级为产品取舍）。

### 2.2 🔁 精简 / 合并

- **合并「AI高亮 + 今日高危 + 精选机会」为一张「信号矩阵 / 机会与风险总览」单表。**
  列建议：`标的 | 方向 | 综合评分 | 校准命中率(样本N) | 回测背书 | 风险应对 | 标签(高亮/高危/观察)`。
  用颜色/标签区分，替代当前三块各渲染一遍 + `owners` 折叠去重。直接消除最脆弱的 dedupe 代码路径，并解决"同一标的反复出现"的观感问题。
- **「赛道轮动」保留。审计 P1 已修（`855ce34`）**：原实现**不是等权平均**，而是**当前市值加权**（`SUM(mcap_now×r)/SUM(mcap_now)`）——用**事后市值**做权重，已被暴涨币（DHN 7日 +15115.4%）过度放大成 Infrastructure 7日 +2497.6%。现改为**期初市值加权**（权重 = `mcap_now/(1+r/100)`，r ≤ -100% 剔除防除零），实测 infra 7d → **26.88%**。故「显式标注等权平均」的建议已不再适用（现口径本就是市值加权）。

## 3. 推荐重排骨架（顶层顺序）

```
顶部：今日3句话（AI定调·降级版，不再含硬价格）
护栏：信号失配期横幅 + 数据状态（诚实，信任锚）
核心数据：大盘脉搏 → 每日变化榜 → 赛道轮动（市值加权）
资金与风险：机构资金流(ETF/稳定币) → 清算杠杆风险(新) → 链上异动(巨鲸+聪明钱)
机会与风险总览（合并 高亮/高危/精选机会 为单表）
硬核深挖(新)：联动归因 + 异动解读 + 信号后验
催化剂与宏观事件
持仓提示(MVRV止盈)
脚注：其他信号（宏观背离等薄项折叠）
```

设计原则：
- **单一结论源**：每个标的/信号只在一处出现，废除 `owners` 折叠去重的反向修补。
- **信任优先**：数据状态 + 告警质量固守顶部锚位；任何降级维度不得作为结论依据（延续审计加分项）。
- **能力即板块**：项目已算出的联动 / 清算 / 后验 / KOL 直接板块化，不再藏进脚注。
